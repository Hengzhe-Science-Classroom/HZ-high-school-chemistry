## Features

- **Interactive visualizations** — molecular models, reaction animations, orbital diagrams, equilibrium simulations, all on Canvas 2D
- **KaTeX math rendering** — clean notation throughout
- **Bilingual content** — Chinese topics with English annotations
- **Exercises with hints & solutions** — from conceptual questions to calculation problems
- **Progress tracking** — saved locally in your browser
- **Zero dependencies** — just open the link and learn
